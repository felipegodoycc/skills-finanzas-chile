# 📖 Fuentes consultadas

Este es el listado completo de las fuentes que usan las skills, con su enlace. Cada skill cita además, junto a cada dato, la fuente y la fecha de consulta.

## Cómo leer este listado

Las fuentes **no valen todas lo mismo**, y este listado lo dice en cada fila. Se clasifican en cuatro grupos:

| Grupo | Qué es | Cómo la usa una skill |
|---|---|---|
| **A. Norma oficial** | Ley, decreto ley, DFL, decreto o norma de un regulador (CMF, Superir, SII, Superintendencia de Pensiones), publicada por el emisor, la BCN o el Diario Oficial | Como hecho normativo. Sube una skill a N3 solo si el texto se leyó |
| **B. Orientación oficial** | Fichas, preguntas frecuentes, comunicados y guías de organismos públicos (CMF Educa, SERNAC, ChileAtiende, TGR, SII, Cámara de Diputados) | Como explicación oficial de una norma; no reemplaza el texto legal |
| **C. Estudio** | Investigación académica o de bancos centrales, chilenos o extranjeros | Como evidencia descriptiva o criterio de método. **No es norma** |
| **D. Solo referencia** | Prensa, estudios jurídicos, blogs, comparadores privados, gremios y fuentes oficiales extranjeras aplicadas por analogía | Para contexto o para detectar cambios. **Nunca** como sustento único de una cifra |

Y cada fuente tiene un **estado de lectura**:

- **Completo**: se leyó el documento entero.
- **Artículos**: se leyeron solo los artículos o secciones que se indican.
- **Extracto**: solo se vio un resumen oficial o una fuente secundaria; la skill lo marca como no verificado.
- **No leído**: citado como base legal o como dato de contexto, sin lectura del texto.

**Sobre los enlaces** (buscados el 27-11-2026):

- Los enlaces a leyes apuntan a la BCN (leychile.cl), que muestra **la versión vigente al abrirlos**. La versión que se leyó está indicada en la fila; si la BCN muestra otra más nueva, puede haber cambios que las skills todavía no recogen.
- Varios textos se leyeron desde PDFs de la BCN descargados a mano, porque la página carga con JavaScript.
- Los dos decretos de Hacienda de la Ley 20.009 enlazan a la edición del Diario Oficial de su fecha de publicación, identificada por búsqueda.

## D. Solo referencia

No sustentan ninguna cifra por sí solas. Se usan para contexto, para detectar un cambio que luego se busca en la fuente oficial, o como criterio extranjero aplicado por analogía.

El **criterio de prioridad de deudas** de `plan-refinanciamiento` se apoya en estas fuentes y en los estudios del grupo C. En Chile no hay una jerarquía oficial (ni en la CMF, el Banco Central, la Superir ni el SERNAC), así que es una **sugerencia de referencia (N1-N2)**, no una regla.
